# Vocal Translate AI v8 — новий підхід до перекладу пісень

> **Експериментальна гілка:** `feat/v8-vocal-first`. Не замінює v7.6 у `main`; повний аудіорендер на RTX 5080 Laptop ще не перевірявся.

## Навіщо змінили підхід

v7 намагався розкласти український текст на склади, прив'язати їх до слів Whisper, автоматично витягнути ноти pYIN і створити спів у DiffSinger. Це давало неприродну артикуляцію, довгі голосні та хибні наголоси.

**v8 не використовує Whisper/F0/USTX/DiffSinger для створення нового вокалу.** Замість цього система приймає **цілу проспівану українську вокальну партію**: або з ACE-Step 1.5 Cover, або зі стороннього синтезатора/мікрофона. Після цього Seed-VC переносить дозволений тембр, а FFmpeg зводить його з інструменталом, виділеним з оригіналу.

Важливо: ACE-Step — генеративна модель, а не точний інструмент заміни мовлення. Вона **може змінювати слова, ритм і мелодію**. Фінальний мікс ACE-Step не використовується; із нього береться тільки новий вокал після Demucs. Інструментал теж отриманий через Demucs, тому він не ідентичний студійному мінусу.

## Схема

```text
Оригінал song.mp3 + lyrics.txt
             │
             ▼
    ACE-Step 1.5 Cover
             │
             ▼
  work/song/ace_guides/guide_01.wav    ──── слухаємо українську вимову
             │
      [ЗУПИНИТИ ACE API]
             │
             ▼
         Demucs
    (лише новий вокал)
             │
  вирівнювання тривалості
             │
             ├─────────────► *_uk_guide.mp3 (з оригінальним інструменталом)
             │
             ▼
      Seed-VC (тембр)
             │
             ▼
   original Demucs instrumental + FFmpeg
             │
             ▼
           *_uk.mp3
```

## Перший запуск на Windows 11 / NVIDIA RTX 3080 Ti або RTX 5080 Laptop

### 1. Підготуйте нову гілку

У PowerShell:

```powershell
git clone -b feat/v8-vocal-first https://github.com/garik816/vocal-translate-ai.git C:\work\vocal-translate-ai-v8
cd C:\work\vocal-translate-ai-v8
.\SETUP_ONLY.bat
```

Встановлення У v8 `setup.ps1` перевіряє `vocal_generation_mode` у `config.json`. Якщо обрано `external_guide` або `ace_cover`, **OpenUtau, DiffSinger і .NET 10 не встановлюються та не збираються**. Для режиму `diffsinger` попередні залежності залишаються доступними. Повторні BAT-запуски використовують наявний Python-venv.

### 2. Встановіть і запустіть ACE-Step 1.5

У **другому вікні PowerShell** в папці Vocal Translate AI виконайте:

```powershell
.\START_ACE_API.bat
```

Скрипт перевірить `http://127.0.0.1:8001/health` і за потреби клонує ACE-Step у сусідню папку `C:\work\ACE-Step-1.5`, встановить його залежності через `uv sync` та запустить локальний REST API. Під час першого запуску завантажуються моделі. Діагностика: **`logs/ace_server.log`** (весь stdout/stderr Python, у тому числі завантаження моделі) та `logs/ace_api.log` (PowerShell). Вікно API **не закривайте**, поки працює `ACE_ONLY.bat`.

Для іншої папки ACE-Step можна перед запуском вказати `$env:ACE_STEP_DIR = 'D:\AI\ACE-Step-1.5'`.

Офіційна інструкція: https://github.com/ace-step/ACE-Step-1.5/blob/main/docs/en/INSTALL.md .

Для RTX 5080 Laptop 16 ГБ доцільно почати з `acestep-v15-turbo`, `batch_size=1`, без LLM. Не тримайте ComfyUI/Ollama з великими моделями в пам'яті одночасно.

### 3. Покладіть оригінал та українські слова

```text
input/
├── song.mp3
└── lyrics.txt
```

`lyrics.txt` — ваш готовий **еквіритмічний** текст із секціями `[Verse]`, `[Chorus]`, `[Outro]`; транскрипція оригіналу НЕ підходить.

### 4. Згенеруйте кавер без Seed-VC і Demucs

`ACE_ONLY.bat` тепер очікує до **600 секунд**, поки `http://127.0.0.1:8001/health` повідомить `models_initialized=true`. Стан завантаження видно у вікні ACE API та `logs/ace_server.log`. За потреби змініть `ace_ready_wait_s` у `config.json`; Ctrl+C зупиняє очікування.

Перевірити готовність API можна у PowerShell:

```powershell
Invoke-RestMethod http://127.0.0.1:8001/health | ConvertTo-Json -Depth 4
```


**Увага:** `GUIDE_ONLY.bat` **не генерує** кавер. Він приймає готовий `input/guide.wav` або вже створений ACE-Step кавер. Тому спочатку потрібні `START_ACE_API.bat` та `ACE_ONLY.bat`.

В іншому PowerShell у папці `vocal-translate-ai-v8`:

```powershell
.\ACE_ONLY.bat
```

Результат: `work/song/ace_guides/guide_01.wav`. Це **повна AI-запис** з музикою, а не готовий чистий вокал. Спочатку послухайте її: чи зрозумілі українські слова, чи не зламана мелодія, чи збережена структура.

**Після генерації зупиніть ACE-Step API** (Ctrl+C у вікні сервера) — на 12 ГБ VRAM інакше може не вистачити пам'яті для Demucs/Seed-VC.

### 5. Виділіть новий вокал і прослухайте без перенесення тембру

```powershell
.\FROM_ACE_GUIDE_ONLY.bat
```

Система:
- виділить новий вокал ACE-Step через Demucs;
- відкоригує **лише загальну тривалість** до оригінальної;
- збере попередній мікс з інструменталом оригіналу.

Альтернатива після ACE_ONLY: `GUIDE_ONLY.bat` тепер автоматично знаходить кешований кавер, якщо немає окремого `input/guide.wav`.

Результат: `out/song_uk_guide.mp3`. Якщо слова або ноти все ще погані, Seed-VC **не допоможе** — потрібно змінити параметри ACE-Step та заново створити кавер.

### 6. Перенесіть тембр

```powershell
.\FROM_ACE.bat
```

Альтернатива: `RUN.bat` автоматично вибирає чистий вокал або вже готовий ACE-Step кавер.

Результат: `out/song_uk.mp3`. Seed-VC використовує чистий референс `input/reference.wav` або автоматично виділений вокал оригіналу.

## Параметри для першого експерименту

У `config.json`:

| Параметр | Рекомендація |
| :-- | :-- |
| `vocal_generation_mode` | `"external_guide"` — для `RUN.bat`; staged launcher має власні прапорці |
| `ace_api_url` | `"http://127.0.0.1:8001"` |
| `ace_ready_wait_s` | `600` — максимальне очікування завантаження моделі ACE-Step |
| `ace_model` | `"acestep-v15-turbo"` |
| `cover_strength` | `0.80` для початку; можна порівняти з `0.65` |
| `ace_seed` | `42` для повторюваних порівнянь |
| `ace_batch_size` | `1` |
| `post_ace_demucs` | `true` — обов'язково, щоб не дублювати музику |
| `guide_max_duration_deviation` | `0.08` — відхилення більш ніж 8% викликає помилку |
| `guide_offset_seconds` | `0.0` — додаткове ручне зміщення вокалу |

Якщо ви змінили текст/параметри, але програма бере старий кавер, виставте `"reuse_ace_guides": false` або запустіть повторно `ACE_ONLY.bat` з новим `ace_seed`. 

## Альтернативний шлях: чистий вокал без ACE-Step

Можна виконати той самий процес з українським співом, записаним на мікрофон або отриманим в іншому синтезаторі.

**Одну пісню:**

```text
input/
├── song.mp3
└── guide.wav          # тільки вокал, з повною часовою шкалою пісні
```

**Кілька пісень:**

```text
input/guide/song1.wav
input/guide/song2.wav
```

У `config.json` залиште `"vocal_generation_mode": "external_guide"` та `"external_guide_is_mix": false`. Запустіть `GUIDE_ONLY.bat`, потім `RUN.bat`. Вокал повинен містити тишу до вступу і в інструментальних паузах, щоб збігатися з оригінальним таймлайном.

Якщо подаєте **готовий мікс** (наприклад, із зовнішнього генератора), змініть `"external_guide_is_mix": true`: Demucs виділить із нього новий вокал.

## Обмеження і критерії якості

- **Не копіюємо** заново створені інструменти ACE-Step у фінальний MP3: використовується оригінальний інструментал після Demucs.
- FFmpeg коригує лише **загальну довжину** та необов'язковий `guide_offset_seconds`. Він **не виправляє** неправильні початки окремих фраз; для цього потрібне окреме time-warp редагування.
- Seed-VC не виправляє неправильні слова, наголоси або ноти.
- Спочатку оцінюємо `guide_01.wav`, потім `*_uk_guide.mp3` і лише потім `*_uk.mp3`.
- Цей workflow ще **не перевірено на реальному аудіорендері** з ACE-Step; Python-тести перевіряють лише логіку маршрутизації й таймінгу. У наданих логах локальної машини визначено RTX 5080 Laptop (16 ГБ), тож опис підходить і для неї.
- Для використання впізнаваного голосу й публікації потрібні відповідні права та дозволи.

Старий шлях залишається доступним: `"vocal_generation_mode": "diffsinger"` та звичайний `RUN.bat`.

## Внутрішні компоненти

- `vta/ace.py` — генерація cover через REST API ACE-Step.
- `vta/guide.py` — пошук зовнішнього вокалу та нормалізація тривалості.
- `vta/audio.py` — відділення оригінального та нового вокалу, зведення.
- `vta/seed.py` — перенесення тембру.
- `tests/test_v8_pipeline.py` — тести маршрутизації без моделей і відеокарти.

# 🚀 Швидкий старт — Vocal Translate AI v7.6

> Повна документація: [README.md](README.md). Запуск орієнтований на **Windows 10/11 + NVIDIA GPU**.

## 1. Встановлення

Відкрийте PowerShell:

```powershell
git clone https://github.com/garik816/vocal-translate-ai.git
cd .\vocal-translate-ai

# Тимчасово, поки v7.6 перебуває в окремій гілці:
git switch fix/v7-6-vocal-quality

.\SETUP_ONLY.bat
```

Інсталятор використовує `winget` і завантажує потрібні залежності (Python через uv, Git, FFmpeg, .NET 10 SDK, моделі). Перший запуск потребує інтернету. Логи — `logs/setup.log`.

## 2. Підготуйте файли

**Одна пісня:**

```text
input/
  song.mp3
  lyrics.txt
```

`lyrics.txt` — **готовий україномовний еквіритмічний текст**, не оригінальні слова й не автоматично згенерований переклад. Збережіть файл як UTF-8; заголовки секцій позначайте `[Verse 1]`, `[Chorus]`, `[Bridge]`. Рядки бажано ділити за музичними фразами.

**Кілька пісень:**

```text
input/
  song1.mp3
  song2.mp3
  lyrics/
    song1.txt
    song2.txt
```

Назви TXT у пакетному режимі повинні відповідати назвам MP3.

## 3. Прослухайте проміжний український вокал

```powershell
.\GUIDE_ONLY.bat
```

Потім перевірте `out/song_uk_guide.mp3`. **Якщо мелодія, паузи або дикція вже неправильні, не запускайте бездумно Seed-VC:** спочатку виправляйте вирівнювання та текст.

Для аналізу нот і часових інтервалів:

- `work/song/diffsinger/guide.ustx` — ноти та українські слова.
- `work/song/diffsinger/alignment.json` — розподіл рядків.
- `work/song/melody/melody.json` — знайдена мелодія.

## 4. Отримайте фінальну пісню

```powershell
.\RUN.bat
```

Результат — `out/song_uk.mp3`. Його створюють Seed-VC (наближення тембру до оригінального виконавця) і FFmpeg (мікс вокалу з інструменталом). Це не гарантує ідентичності тембру або повного збереження якості оригінального міксу.

## 5. Додаткові режими

| Команда | Призначення |
| :-- | :-- |
| `.\EXTRACT_LYRICS.bat` | Витягти слова оригіналу + таймінги у `out/*_source_lyrics.*` |
| `.\GUIDE_ONLY.bat` | Згенерувати guide без Seed-VC |
| `.\SETUP_ONLY.bat` | Встановити/перевірити середовище |
| `.\DIAGNOSE.bat` | Записати діагностику до `logs/diagnose.log` |
| `.\FORCE_REPAIR.bat` | Примусово перевстановити/перевірити компоненти |

**Зразок голосу (необов'язково):** `input/reference.wav` або окремий `input/reference/song.wav`. Якщо його немає, референс береться з вокалу оригіналу.

**Додатковий фінальний приспів:** існуючий останній `[Chorus]` залишайте звичайним; лише для **нової** секції в кінці використовуйте `[Chorus repeat]`. Параметр `append_final_repeated_section` у `config.json` має бути `true`.

## 6. Якщо не працює

- Встановлення → `logs/setup.log`.
- Розділення доріжок → `logs/demucs.log`.
- Розпізнавання/ритм → `logs/asr.log`, `logs/melody.log`.
- Українська вимова → `logs/diffsinger.log`.
- Перенесення тембру → `logs/seed_vc.log`.
- Фінальне зведення → `logs/ffmpeg.log`.

Запустіть `.\DIAGNOSE.bat` і звірте лог помилки. Застарілі інструменти попередніх версій (`ACE-Step`) у поточному українському конвеєрі не використовуються.

> **Статус:** експериментальний. Публікація пісень із впізнаваним голосом виконавця та використанням оригінальної фонограми потребує відповідних дозволів.
